# Gator

Gator is a command-line RSS feed aggregator written in TypeScript and Node.js.

It allows users to register, add RSS feeds, follow feeds, continuously fetch posts, and browse recent posts directly from the terminal.

## Requirements

You will need:

- Node.js
- npm
- PostgreSQL
- TypeScript
- Drizzle ORM

This project uses Node.js 22.15.0.
